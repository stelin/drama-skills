# 观看契约：让竖屏默认让位

本套件的镜头工艺以竖屏快节奏短剧为默认取向，而且这个取向不只写在默认值里，也写在示例、调度手册
和题材卡的语境里。做电影长片、横屏剧集或静态漫剧时，只在配置里改画幅不够——模型读到的示例仍然
是竖屏的。观看契约是创作者写在《视觉设定.md》里的一行声明，它做两件事：让点名的竖屏
`craft_default` 整体让位，并告诉每个阶段本项目的观看条件是什么。

**`SHT-26 · craft_default`**：项目在《视觉设定.md》「项目视觉方向」声明观看契约后，本文列出的
竖屏取向默认整体让位于契约声明的取向；未声明时维持套件默认。契约本身不产生任何数字门槛。

## 声明语法

写在《视觉设定.md》一级标题之后、第一个资产条目之前的「项目视觉方向」段，一行一项：

```markdown
## 项目视觉方向

- 观看契约：电影长片 · 16:9 · 剧场感 · 慢节奏
- 制作形态：实拍
- 摄影系统：数字实拍 · 大画幅传感器 · 定焦球面镜头家族 · 24fps · 需要胶片感时写印片模拟
- 世界坐标：中国东北 · 1998–2003 · 无智能手机 · 固定电话与传呼机 · 燃煤供暖
```

`观看契约` 第一项取封闭词表；画幅按 `short-drama.json#/format/aspect_ratio`（`project_tool.py init --aspect-ratio 16:9`）；
其余是项目自定义标签，供各阶段读取。「项目视觉方向」不是资产条目，`creator_markdown_check.py` 不解析它。

## 契约值

| 值 | 含义 | 默认交付面 |
|---|---|---|
| `竖屏短剧` | 套件默认；信息流播放，注意力按切镜购买 | 9:16，播放面有叠加区（按 `SHT-15` 声明） |
| `横屏剧集` | 电视/流媒体剧集节奏 | 16:9，无播放面叠加 |
| `电影长片` | 剧场或大屏观看，观众已经坐定 | 16:9 或 2.39:1，无播放面叠加 |
| `静态漫剧` | 关键帧切换加配音 | 按项目 |

## 电影长片让位的默认

下面每一条在原文件里都标了 `craft_default`，契约声明为 `电影长片`（或 `横屏剧集`）时整体不生效：

| 原默认 | 所在 | 让位后 |
|---|---|---|
| 子镜密度大致每 4–8 秒一次 | 分镜技能《生产镜头语法》第七节 | 切镜密度由场次注意力、压力与信息变化解释，不设带宽 |
| 地理在动作内部到达，不补仪式化全景 | 同上第三节 | 建立镜头是合法选择：空景、缓慢定场、让观众先迷失再定位都可以，仍要能说出它交代了什么 |
| 高度变化在竖屏里比横屏更贵 | 同上第五节 | 回到横屏常规读法，俯仰按权力关系正常使用 |
| 竖屏多人调度与交付面遮挡避让 | 分镜技能《调度手册》第一节 | 多人调度按横屏常规；`delivery_surface` 保持 `unset` 且**不作为未决项** |
| 竖屏构图优先保证主体和反应可见 | 分镜技能 SKILL 镜头要求 | 构图按契约的画幅与景别语言 |

让位不是删除：这些段落仍然是竖屏项目的默认，本文只声明它们的适用条件。

## 电影长片新增的默认

同样是 `craft_default`，创作者说明理由即可覆盖：

- **镜头长度只受两样约束**：已接受档案的 `native_duration_seconds`（`SHT-27`）与叙事需要。长镜优先
  走多镜容器与续接路由（视频提示词技能《交付形态》），不为迁就单次生成上限把一个镜头拆成两个
  镜头目的。
- **工作景别偏宽一档**。两人对峙的工作景别常落在中景而不是中近景；近景与特写仍是离开工作景别的
  标记事件，用过就回来。
- **反应可以留在同一构图里**。不因为一句重台词就切听者近景；固定机位等待表演完成是积极选择。
- **声音按档案决定同轨或分轨**，但配乐仍归时间线层（`VID-14`）。
- **色彩与摄影系统在项目视觉方向锁定一次**（实拍形态卡的「摄影系统一致」），逐镜只写光位与
  光比，不重写介质。

## 各阶段拿走什么

| 阶段 | 读取契约后改变什么 |
|---|---|
| develop / 导演阐述 | 分集地图不按「爽点间隔」组织；集长与幕结构由创作者声明 |
| write | 场景长度与对白密度按剧场观看写；`[连续性]` 标签照旧 |
| assets | 无变化；实拍形态卡的世界坐标与摄影系统写进项目视觉方向 |
| image-prompts | 画幅按契约；设定板版式照旧从版式卡选 |
| storyboard | 上表全部让位项；建立镜头、长镜、固定机位等待成为常规选项 |
| video-prompts | 多镜容器与续接为主要路由；时长核对按原生区间 |
| review | 不得以竖屏默认（切镜密度、避让区、首镜宽景）作为缺陷依据 |

## 不做什么

- 不引入任何镜头长度、切镜数量或每集时长的数字门槛；集时长加总只报告差值（`SHT-16`）。
- 不改写身份、地理、文字政策与已接受镜头边界；契约是取向，不是事实。
- 不新增第六份创作文档；契约只是《视觉设定.md》里的几行。
