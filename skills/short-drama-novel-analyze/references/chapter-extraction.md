## 提取什么

一章提取一份 `章节/第N章-提取.md`，四段固定顺序：

1. **概要**：3–5 句，说这一章在整本书里**改变了什么**。不是缩写剧情，是回答
   「读完这章，谁的处境、认知或筹码和读完上一章时不一样了」。写成条目罗列，
   或整段「因为…所以…」串联，都是没做提取。
2. **情节点**：见下。
3. **出场人物**：本章出现的称谓原样记录，附本章内的作用。**不做跨章归并**——归并是 S4
   的事，在这里做会让每一章各自发明一套人物表。
4. **未决项**：本章无法判断的指代、时间关系或矛盾，逐条列出。留白比猜测便宜。

## 情节点写法

每个情节点一行，四段用 `|` 分隔：

```
P1 类型 | 白描 | 涉及：称谓、物件、地点 | 功能：这一步改变了什么
```

- **类型**取自：`行动`、`对话`、`信息`、`转折`、`铺垫`、`兑现`、`状态`。
- **白描**是可观察的事实：谁做了什么、说了什么、什么被看见。不写心理断言，
  不写作者意图。白描是这条情节点的主要证据——后面每一次事实回查都落在它上面。
- **功能**回答改变了什么：权力、信息、关系、暴露、资源、时间或代价，至少一项。
  写不出功能的情节点，多半不是情节点。

密度按章节字数动态调节，通常一个情节点覆盖 150–200 字原文。不要为凑数拆步骤，
也不要把一整场戏压成一行。

## 深度拆解（开篇三章）

开篇三章在情节点之外多写三段：

- **留人机制**：这一章靠什么让读者读下一章。具体到出现位置，不写「悬念强」。
- **第一个具体承诺**：作品向读者承诺了什么样的回报，以及承诺出现在第几个情节点。
- **代价**：主角第一次做出有代价的选择是什么，代价是否当场兑现。

反派或对抗面不是人形时（体系、灾变、规则、时代压力），按抽象对抗型写：
核心对抗面是什么、紧迫感从哪里来、如何升级、主角用什么替代「打赢一个人」。

## 机械自检

落盘后由主线程直接跑，命中即判失败，不依赖子代理自报。这些检查存在的理由是
下游会按同样的字面形状 grep：格式漂一个字符，聚合阶段就会静默漏掉整章。

```bash
N=$(grep -cE '^P[0-9]+ ' 章节/第N章-提取.md)
grep -cE '^P[0-9]+ [^|]+\|[^|]*[^|[:space:]][^|]*\|[^|]*涉及' 章节/第N章-提取.md   # 必须 == N
grep -cE '功能：' 章节/第N章-提取.md                                              # 必须 == N
grep -hoE '^P[0-9]+ [^|]+' 章节/第N章-提取.md | awk '{print $2}' | sort -u          # 必须 ⊆ 类型表
```

- 白描段计数少于 `N`：有情节点缺白描，或字段顺序、分隔符不对。
- `功能：` 计数少于 `N`：有情节点没回答改变了什么。注意全角冒号——半角会漏。
- 类型超出枚举：自造类型会让 S3 的归类整段落空。

## 并发与串行

**两条路径的写法要求和自检是同一份**，区别只有速度。

- **并发**：每批 5–8 章，一批全部落盘再发下一批，每批结束更新 `_progress.md`。
  每条子任务的提示必须自带材料授权前缀，说明这是创作者合法持有的虚构作品、
  任务是只读的转化性分析、通俗题材的黑暗元素照常提取——否则子代理会把正常的戏剧化
  情节误判为有害内容并拒绝整章，而主线程只会看到一个空结果。
- **串行**：主线程逐章处理，同样跑机械自检。

运行环境不支持子代理、或本技能已在子代理上下文里运行时，直接走串行，并在汇报里说明。

## 失败处理

| 情况 | 处理 |
|---|---|
| 子代理崩溃、超时、空输出 | 同条件重试 1 次 |
| 机械自检不过 | 带上失败项重写本章 1 次 |
| 重试仍失败 | 标记 `⚠️ 跳过`，写入 `_progress.md` 失败记录 |

单章失败不阻断管道。但**跳过的章必须出现在每一份继承它的聚合产物里**——
一份看起来完整、实际缺了第 47 章的分析，比一份明说缺章的分析危险得多。
