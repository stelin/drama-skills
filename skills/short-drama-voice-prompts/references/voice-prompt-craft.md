## 身份与表演的界线

一句话判定：**这个特征在角色安静地坐着说一句无关紧要的话时还在吗？**

在，就是身份，写进锚点。不在，就是表演，留给场次与台词。

| 属于身份 | 属于表演 |
|---|---|
| 音区、音色质感、年龄印象 | 本场因奔跑造成的气息不稳 |
| 语速与停顿习惯、句尾处理 | 某一句的重音位置 |
| 口音与方言范围 | 这一场压低声音说话 |
| 已接受的专名发音 | 情绪激动时的音量 |

界线画错的代价不对称：把表演写进身份，角色每一集都会被要求带着上一集的伤势说话;
把身份漏进表演，配音者每一场都要重新猜这个人是谁。

## 六类锚点

一条锚点写一件可被听出来的事。六类里挑**三到五条**，不要全写满。

1. **音区**：相对位置而不是绝对频率——「比同剧其他成年男性低半档」比 Hz 有用得多，
   因为执行的是人或模型，不是示波器。
2. **质感**：气声多寡、颗粒、鼻腔共鸣、干净或沙哑。
3. **年龄与体量印象**：听上去多大、体格给声音带来什么。注意这是**印象**，
   不是角色的实际年龄，两者可以不一致，且不一致往往正是设计。
4. **节奏**：语速基线、停顿习惯、抢话还是等话、句子收住还是拖长。
5. **口音与语域**：方言范围、受教育程度暗示、行业用语习惯。范围要给边界——
   「带轻微南方口音，不到能指认具体城市的程度」是可执行的，「南方口音」不是。
6. **标记性习惯**：可重复的小特征。至多一条，多了会变成模仿秀。

每条锚点后面跟一个**反例**会让它可执行得多：写清什么算过头。

## 写出区分度

同一批角色**对比着写**。对每个角色回答：同剧里跟他最容易混的是谁，用哪一条锚点区分。

```
CHAR-A 与 CHAR-B 最易混：两人同为中低音区、语速偏慢。
区分锚点：A 句尾收住不拖长；B 句尾常带一段下滑的余音。
```

这条写不出来，说明两个角色的声音设计实际上是同一个。这是设计问题，不是措辞问题——
回到 `$short-drama-assets` 让创作者拉开差异，不要靠堆形容词假装区分。

角色多时按**易混组**分批处理，而不是按出场顺序：把音区相近的放进同一批一起写。

## 专名发音

已接受的专名发音只能有一种拼法，且必须来自 `voice_direction.pronunciation_notes`。

同一个名字在两条规格里出现两种拼法，配音就会在两集之间改口，而这种错在文本审查里
几乎看不出来——它只在成品里被听见。需要新增发音时回到 assets 走接受流程，
不在本阶段就地决定。

## 变体：伪装、年龄与跨段变化

角色装成另一个人、跨越十年、或中毒后长期失声，都**不改写基础身份**，而是记一条变体：

- `cause`：由哪条已接受的剧本事实引起；
- `validity`：从哪里生效到哪里失效；
- `delta`：相对基础身份改了哪几条锚点，其余继承。

短暂的一场变化不建变体，交给表演。判据和 Look 一样：跨多个场次持续、会重复使用、
需要独立参考、或下游必须精确绑定时才升为变体。

## 两个语言分开写

- `spoken_language`：角色说什么语言/方言，来自 `voice_direction.language`。
- `prompt_language`：描述音色的文字用什么语言写，来自项目
  `short-drama.json#/format/prompt_language`。

一个中文项目里，`spoken_language` 是 `zh-CN`，而 `prompt_language` 默认 `en`——
描述文字用英文，因为多数语音工具对英文描述最稳定。这两个值互不影响：
把它们合成一个字段，就会出现「用中文描述所以角色改说中文」这种没人打算做的改动。

创作者可读的说明与自检摘要跟随项目 `language`，与 `prompt_language` 无关。

## 常见失败

| 失败 | 症状 | 怎么改 |
|---|---|---|
| 情绪当音色 | 锚点里出现「愤怒」「悲伤」「紧张」 | 换成产生该印象的可听特征，情绪交回表演 |
| 形容词墙 | 十几个近义修饰堆在一起 | 砍到三到五条硬锚点，每条带反例 |
| 角色写重了 | 几条规格互换名字也读得通 | 补区分锚点；补不出就回 assets 改设计 |
| 工程参数冒充身份 | 出现模型名、采样率、接口字段 | 全部删除；规格要比任何一次调用活得久 |
| 身份漂移 | 新一批规格里出现没被接受过的锚点 | 回溯到 `voice_direction`，没有就走接受流程 |
