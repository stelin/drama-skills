# 电影长片 Creator-first 全流程

与 [漫剧全流程](comic-drama-workflow.md) 用的是同一套技能、同一种五文档；差别在两处：项目开始时声明
**观看契约**，让竖屏短剧的默认整体让位；以及生产档案通常选 30 秒级的长镜模型，把一场戏装进
**交付分组**。完整样例是 [《冻河》第一本](../examples/creator-first-film/)。

## 一眼看懂

```text
剧本或原著
   │
   ├─ 开发（可选）：导演阐述里写世界坐标；全片情绪曲线按需
   ▼
剧本.md
   ▼
视觉设定.md  ←「项目视觉方向」：观看契约 · 制作形态 · 摄影系统 · 世界坐标
   │            人物条目：派生自 / 派生关系 / 派生状态 · 连续性锁
   │            道具条目：尺度
   ├──────────────┐
   ▼              ▼
图片提示词.md    分镜.md  ←「省略的对白」· 建立镜头与固定机位等待是常规选项
（版式卡）        ▼
              视频提示词.md  ← 方言正文 · 末尾「交付分组」+ 四级标题容器正文
                   │
   机械核对：creator_markdown_check.py --dialogue-coverage · dialect_check.py
                   ▼
            预览 → 明确确认 → 生产（codex-imagegen 零 key 出图 / Seedance 2.5 续接）
```

## 1. 初始化：画幅与档案

```text
用 $short-drama 初始化一个横屏电影项目《冻河》，16:9，中文提示词，单本目标 65 秒
```

再把目标视频模型写进档案（会话里点名不落档案，下一轮就退回通用路径）：

```text
本项目按 Seedance 2.5 写视频提示词，先把它写进 production_profile
```

档案带来的原生时长区间（Seedance 2.5 是 4–30 秒）从分镜阶段起就生效（`SHT-27`）。

## 2. 写 `剧本.md`

与漫剧相同的格式。电影的场景可以更长、对白更稀；`[连续性]` 标签照旧只交接容易丢的状态。

## 3. 写 `视觉设定.md`：先声明契约，再拆资产

```text
用 $short-drama-assets 从 EP001 拆完人物、地点、道具；观看契约是电影长片，制作形态实拍
```

「项目视觉方向」段写在一级标题之后、第一个资产条目之前：

```markdown
## 项目视觉方向

- 观看契约：电影长片 · 16:9 · 剧场感 · 慢节奏
- 制作形态：实拍
- 摄影系统：数字实拍 · 大画幅传感器 · 定焦球面镜头家族 · 24fps · 需要胶片感时写印片模拟
- 世界坐标：中国东北松花江沿岸小城 · 1999 年冬 · 固定电话与传呼机 · 燃煤炉取暖
```

三件电影项目常用、漫剧少用的事：

- **血亲与派生**：子女、不同演员承担的年龄阶段、变异形态，在派生一方写 `派生自：人物「…」（继承：…；不继承：…）`、
  `派生关系`、`派生状态：待上游定稿`。继承只写 2–4 项骨相；上游父母没有 `用途：身份` 的定稿图之前，派生条目
  不能被镜头绑定为身份图（`AST-15`）。见 `$short-drama-assets` 的《血缘与派生》。
- **尺度**：会被反复贴进镜头的道具写 `尺度：手持级 | 桌面级 | 家具级`，图片提示词正文必须带对应短语（`IMG-16`）。
- **连续性锁**：跨镜不变的服装主色与形制上锁，锁面用提示词语言写最小名词短语。

## 4. 写 `图片提示词.md`：从版式卡选

```text
用 $short-drama-image-prompts 为 EP001 写角色板、场景板和道具板；角色板选面部基准三视板或服装发型核对板
```

三张卡回答同一组问题（解决什么 reuse_job、版面、光照分区、最常崩的地方）；派生条目的身份板 `参考：` 用父母定稿图
各占一个 `用途：身份` 的 `REF-`，`控制：` 只写继承项，`不得控制：` 逐字带上不继承项。道具板可选 3:4 单件档案照。

## 5. 写 `分镜.md`：契约让位后的镜头

```text
用 $short-drama-storyboard 完成 EP001 的正式分镜和每镜冻结关键帧
```

观看契约声明后，竖屏的切镜密度带宽、「地理在动作内部到达」、竖屏高度代价与播放面避让整体不生效（`SHT-26`）：
建立镜头、固定机位等待表演、工作景别偏宽一档都是常规选项。镜头 `时长` 只受原生区间与叙事约束；未定的写 `待定`。
确实不由镜头承载的对白，在第一个镜头之前写 `## 省略的对白`，一行一句。

## 6. 写 `视频提示词.md`：方言正文与交付分组

```text
用 $short-drama-video-prompts 按 Seedance 2.5 把 EP001 分镜逐镜写成视频提示词；平房一场三镜装一个容器
```

- 逐镜 `MOTION-...` 正文照旧；Seedance 2.5 用 `镜头 k [a–b]` 时间戳，H3 用 `[Shot k] At mm:ss.mmm,`；
- 同场连续的镜头要一次生成时，在文档末尾写 `## 交付分组`：`### GROUP-... · 名称` 下列成员、容器时长、成员理由，
  容器自己的正文用 `#### 可复制提示词`；容器时长等于成员时长之和，一个镜头最多进一个分组（`VID-13`/`VID-15`）；
- 续接路由：第二段起绑定上一段实际视频与实际尾帧，见《交付形态》。

## 7. 机械核对：两条命令

```bash
python3 <core>/scripts/creator_markdown_check.py 剧集/EP001 --project-root . --dialogue-coverage
python3 <video-prompts>/scripts/dialect_check.py 剧集/EP001 --project-root .
```

第一条核对跨文档契约、派生解析与就绪、时长账目（只报告差值）、原生区间、交付分组算术、尺度短语，`--dialogue-coverage`
打开时再核对每句对白是否被视频正文或分镜声音字段逐字承载、或已显式省略（`VID-26`）。第二条按已接受方言
逐字对账素材编号、切点时刻、时间戳区间与围栏内台词（`VID-25`）。都只读不写。

## 8. 生产：零 key 出图与长镜续接

```text
用 $short-drama-produce 预览 EP001 的角色板任务，adapter 用 codex-imagegen；等我确认后再执行
```

`codex-imagegen` 走本机 codex 登录态，不读 API key；仍然 `prepare → confirm → run`。出来的定稿图先绑成派生条目
上游的 `用途：身份` `REF-`，再出子女的身份板；分镜起始帧同样可以由它从冻结关键帧渲染。视频走 Seedance 2.5 adapter，
续接段绑定上一段实际视频与实际尾帧。

## 常见卡点

| 卡点 | 处理方式 |
|---|---|
| 分镜仍按竖屏节奏切、首镜不给空景 | 确认《视觉设定.md》「项目视觉方向」里有 `观看契约：电影长片`；没有就补，不在分镜里逐镜解释 |
| 子女出图后与父母无关，或父母改骨相子女作废 | 先出父母定稿图并绑成 `用途：身份` 的 `REF-`，再出子女；机械核对会在顺序反了时报「派生上游未定稿」 |
| 容器正文的时间戳改了秒数忘改 | `dialect_check.py` 逐字对账；改时长先改《分镜.md》，容器时长与时间戳随之重算 |
| 手持道具被画成家具尺寸 | 道具条目写 `尺度`，正文带短语；`IMG-16` 会拦漏掉的那条 |
| 全集拼起来超长 | 看 `creator_markdown_check.py` 的 `INFO 本集 … 镜时长合计`；差值只报告，回内容层合并或拆分，不按数字均匀砍 |
| 没有 API key 看不到画面 | 用 `codex-imagegen` adapter 出图；画风跨图不一致时把第一张成图绑成 `用途：风格` 的 `REF-` |
